A lightweight SIEM built from scratch

Micro-SIEM ingests real web login attempts and Nginx access traffic — detects brute-force and password-spraying attacks, credential compromise patterns, and XSS injection attempts — and shows it all live on a role-based dashboard. Built as a final-year cybersecurity project.

Enter Demo Portal
📡

Multi-Source Ingestion

Reads custom web login events and Nginx access logs — independent, live data sources feeding one pipeline.

🧠

Real Detection Logic

Brute-force and password-spraying rules, a true cross-event correlation rule (fail-then-success), and signature-based XSS detection — not a black box.

🗺️

MITRE ATT&CK Mapped

Alerts are tagged with real technique IDs (T1110 Brute Force, T1110.003 Password Spraying, T1078 Valid Accounts) where they genuinely apply — no forced mappings.

📊

Role-Based Dashboards

Separate Admin and Viewer consoles, session-token authenticated — full response actions for admins, read-only visibility for viewers.

🔓

Intentional Attack Surface

This portal itself is the test target — a deliberately vulnerable login and search page for live, safe demonstration of real attacks.

⚙️

Fully Containerized

Every component — ingestion, storage, API, dashboards — runs in Docker, orchestrated with a single Compose file.
